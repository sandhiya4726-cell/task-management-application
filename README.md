# Task Management Application

A web-based Task Management Application built using Python and Django to help users organize and manage their daily tasks efficiently.

## Features

* User registration and login
* Secure user authentication using Django
* Add new tasks
* View and manage tasks
* Edit existing tasks
* Mark tasks as completed
* Delete tasks
* User-friendly interface with CSS styling

## Technologies Used

* Python
* Django
* HTML
* CSS
* SQLite
* Git and GitHub

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/sandhiya4726-cell/task-management-application.git
```

### 2. Open the project folder

```bash
cd task-management-application
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

On Windows:

```bash
venv\Scripts\activate
```

### 5. Install Django

```bash
pip install django
```

### 6. Apply database migrations

```bash
python manage.py migrate
```

### 7. Start the development server

```bash
python manage.py runserver
```

Open your browser and visit:

`http://127.0.0.1:8000/`
